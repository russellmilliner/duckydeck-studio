DuckyDeck Studio (v0.1.6) is a native Linux (KDE Plasma 6 / Wayland & X11) and Windows 10/11 (x86_64) configurator, DSVM v2 bytecode compiler, Window-Aware Auto-Switcher, and Macro Template Generator (experimental) for the duckyPad Pro (2024) and duckyPad (2020), crafted with Rust, CXX-Qt, Qt 6, and KDE Plasma 6 Kirigami.

⚡ Hardware Portability vs. Host-Dependent Capabilities

DuckyDeck Studio combines standalone hardware configuration (compiled onto your duckyPad's microSD card) with host-assisted Linux & Windows desktop automation. Throughout the app, every feature is badged as either ✅ Hardware-Portable or 💻 Requires DuckyDeck Studio Running on Host PC so you always know what works when you unplug your duckyPad and move it to another computer.

Capability Portability Requires DuckyDeck Studio Running? Details
Standard duckyScript 3 Macros (keyN.txt → .dsb) ✅ Hardware-Portable No (once synced to SD) Keyboard shortcuts, STRING/STRINGLN, mouse moves, media keys, loops, and GOTO_PROFILE run natively on the duckyPad MCU on any OS.
Key Labels, Static RGB Colors & Key Lighting Scripts (SWCC/SWCF/SWCR) ✅ Hardware-Portable No (once synced to SD) Stored directly in config.txt and .dsb bytecode on the microSD card.
OLED Orientation (0°, 90°, 180°, 270°) ✅ Hardware-Portable No (once synced to SD) Saved to config.txt on the microSD card (180°/270° require DuckyDeck Studio Firmware v1.1.1).
🚀 Launch Application Action (APP badge) ⚠️ Host-Dependent (Not Portable) Yes (must be running on Host PC) Emits a silent _GV31 USB HID trigger or F13–F24 hotkey that DuckyDeck Studio listens for on your Linux or Windows PC to spawn local apps.
🌐 Web API / HTTP Webhook Action (API badge) ⚠️ Host-Dependent (Not Portable) Yes (must be running on Host PC) The duckyPad has no Wi-Fi/Ethernet stack; DuckyDeck Studio executes the HTTP request on the host PC when triggered via USB HID.
🌈 Live RGB Ambient Animator (Rainbow Wave / Breathing / Reactive) ⚠️ Host-Dependent (Live USB HID) Yes (must be running on Host PC) Streams 20 FPS RGB frames over USB HID 0x17. Stopping DuckyDeck Studio restores the profile's static SD card colors.
🪟 Window Auto-Switcher (KWin Wayland / Windows Win32) & Floating OLED Desktop Widget ⚠️ Host-Dependent (Linux & Windows) Yes (must be running on Host PC) Uses a KWin Wayland D-Bus hook on Linux or Win32 GetForegroundWindow tracker on Windows to switch profiles when active windows change and render the desktop widget.
💡 In-App Portability Indicators
Whenever a key uses a host-dependent capability (🚀 Launch App or 🌐 Web API), the Right Key Inspector displays an amber 💻 Host-Dependent Action — Requires DuckyDeck Studio Running banner, and the dialog headers for Launch App, Web API, Live RGB Animator, and Auto-Switcher clearly state that the feature requires DuckyDeck Studio running in the background or system tray.

📦 1. Downloading, Windows / Linux Installation & USB HID Permissions

DuckyDeck Studio (v0.1.6) is open-source and available for Windows 10 & 11 (x86_64) (Setup Installer .exe & Portable .zip) and Linux (x86_64) (Universal Flatpak bundle, prebuilt tarball, or built from source) on github.com/russellmilliner/duckydeck-studio and duckydeckstudio.com.

Step 1: Choose Your Platform & Installation Method

🪟 Option A: Windows 10 & 11 Installer or Portable ZIP (x86_64)

Zero extra drivers are required on Windows 10/11—Windows automatically binds the duckyPad's USB HID interface and microSD drive on plug-in:

  • Setup Installer (Recommended): Download and run DuckyDeck-Studio-Setup-v0.1.6-x86_64.exe (installs per-user to %LOCALAPPDATA%\Programs\DuckyDeck Studio with Start Menu, Desktop shortcut, and optional Autostart at Windows Login).
  • Portable ZIP (No Installer Required): Download and extract duckydeck-studio-v0.1.6-windows-x86_64-portable.zip, then launch duckydeck-studio.exe.

🐧 Option B: Linux Flatpak Bundle (Recommended — Any Linux Distro)

Download the self-contained Flatpak bundle (io.github.duckydeck.Studio) from duckydeckstudio.com or GitHub Releases: 

# 1. Ensure the KDE 6.11 Flatpak runtime is available from Flathub:
flatpak remote-add --if-not-exists --user flathub \
    https://flathub.org/repo/flathub.flatpakrepo

# 2. Download & install the DuckyDeck Studio Flatpak bundle:
curl -LO https://duckydeckstudio.com/releases/duckydeck-studio-v0.1.6-x86_64.flatpak
flatpak install --user -y duckydeck-studio-v0.1.6-x86_64.flatpak

# 3. Launch DuckyDeck Studio (or open from your KDE Application Launcher):
flatpak run io.github.duckydeck.Studio

# 4. Run CLI status or automation commands via Flatpak:
flatpak run io.github.duckydeck.Studio --status

📥 Option C: Download Prebuilt Linux x86_64 Tarball or Clone Git Repo

Download the prebuilt release tarball (duckydeck-studio-v0.1.6-linux-x86_64.tar.gz) or clone the repository to build from source: 

# Prebuilt Linux x86_64 Tarball:
curl -LO https://duckydeckstudio.com/releases/duckydeck-studio-v0.1.6-linux-x86_64.tar.gz
tar -xzf duckydeck-studio-v0.1.6-linux-x86_64.tar.gz
cd duckydeck-studio-v0.1.6-linux-x86_64
./duckydeck-studio

# Or clone the Git repository:
git clone https://github.com/russellmilliner/duckydeck-studio.git
cd duckydeck-studio

Step 2: Install Linux Build Prerequisites (If Building from Source)

  • Arch Linux / CachyOS / EndeavourOS / Manjaro: 
    sudo pacman -S --needed base-devel rust clang cmake ninja pkgconf \
    qt6-base qt6-declarative kirigami syntax-highlighting hidapi libusb
  • Fedora (40 / 41+): 
    sudo dnf install cargo rust clang cmake ninja-build pkgconf-pkg-config \
    qt6-qtbase-devel qt6-qtdeclarative-devel kf6-kirigami-devel \
    kf6-syntax-highlighting-devel hidapi-devel libusb1-devel systemd-devel
  • Ubuntu (24.04+) / Debian / KDE Neon: 
    sudo apt install build-essential cargo rustc clang cmake ninja-build pkg-config \
    qt6-base-dev qt6-declarative-dev libkf6kirigami-dev \
    libkf6syntaxhighlighting-dev libhidapi-dev libusb-1.0-0-dev libudev-dev

Step 3: Build & Install Native Linux Binary, Flatpak, or Windows Installer from Source

Compile the optimized release binary, build the Flatpak bundle via bash scripts/build-flatpak.sh, or cross-compile the Windows installer via bash scripts/build-windows.sh:

# 1. Compile optimized Linux release binary
cargo build --release

# 2. Install binary to ~/.local/bin
install -Dm755 target/release/duckydeck-studio ~/.local/bin/duckydeck-studio

# 3. Install duckyScript 3 syntax highlighting for KDE KSyntaxHighlighting
install -Dm644 data/syntax/duckyscript3.xml \
    ~/.local/share/org.kde.syntax-highlighting/syntax/duckyscript3.xml

# 4. Install desktop entry, icon, and documentation
install -Dm644 data/io.github.duckydeck.Studio.desktop \
    ~/.local/share/applications/io.github.duckydeck.Studio.desktop
install -Dm644 data/icons/io.github.duckydeck.Studio.svg \
    ~/.local/share/icons/hicolor/scalable/apps/io.github.duckydeck.Studio.svg
install -Dm644 docs/user-guide.html \
    ~/.local/share/duckydeck-studio/docs/user-guide.html
install -Dm644 docs/architecture.html \
    ~/.local/share/duckydeck-studio/docs/architecture.html

# 5. Or build & install the Linux Flatpak bundle from source:
bash scripts/build-flatpak.sh
flatpak install --user -y --reinstall target/release/duckydeck-studio-v0.1.6-x86_64.flatpak

# 6. Or cross-compile the Windows x86_64 Portable ZIP & Setup .exe installer:
bash scripts/build-windows.sh
⚡ Step 4 (Linux Only): One-Click Polkit udev Rule Setup
On Windows 10/11, USB HID access works out-of-the-box with zero configuration. On Linux, if non-root USB HID access is blocked (PermissionDenied on /dev/hidraw*), DuckyDeck Studio automatically displays an inline yellow banner at the top of the window (works in both Native and Flatpak builds). Click Install Rules to authorize the 70-duckypad.rules installation via Polkit, or run: 
sudo ./data/udev/install-udev-rules.sh

🖥️ 2. The 3-Column Workspace

1️⃣ Left Column: Profiles, Templates & Auto-Switcher

Browse up to 64 hardware profiles, filter by profile name or bound application, create profiles from built-in or user Templates, drag-and-drop the ⠿ handle to reorder profiles, click any profile's color bar to change its default LED color (`BG_COLOR`), and monitor or configure KWin Wayland Auto-Switcher rules.

2️⃣ Center Column: Interactive Hardware Canvas

Interact with the 4×5 RGB key matrix (Keys 1–20), Dual Rotary Encoders (Slots 21–26), live 128×128 OLED screen simulator, and 32 Expansion Module channels (Slots 27–58). Drag and drop keys to swap or shift (`Shift + Drag`) slots.

3️⃣ Right Column: Key Inspector & Script IDE

Opens automatically when you click a key or encoder slot. Edit Line 1 / Line 2 OLED labels (up to 7 characters each), toggle Allow Abort and No Repeat, write `On Press` (`keyN.txt`) and `On Release` (`keyN-release.txt`) scripts, or configure no-code 🚀 Launch App and 🌐 Web API actions.

☕ Top Bar & Hamburger Menu (`☰`)

Displays the active application version, active profile badge, quick Default Color button, ☕ Buy Me a Coffee Ko-fi button, and the ☰ Hamburger Menu for SD sync & mounting, profile templates, profile groups, PGV variables, System Event Log, Settings, and About.

🗂️ 3. Profiles, Templates & Profile Groups

The duckyPad Pro supports up to 64 profiles (`profile_1` through `profile_64`). Each profile stores its own default background LED color (`BG_COLOR`), per-key custom colors (`SWCOLOR`), key labels (`zN` / `xN`), OLED & Desktop Widget orientations, and compiled bytecode binaries (`.dsb`).

  • Create a Profile (Blank or From Template): Click + New at the bottom of the left sidebar, type a name (up to 16 characters), optionally select any built-in or user-saved Template from the dropdown, and press Enter.
  • 📋 Profile Templates:
    • Click 📋 Templates... at the bottom of the sidebar (or 📋 Profile Templates... in the `☰` menu) to browse built-in starter templates (Media & Volume Deck, IDE & Git Workflow, Browser & Research, Numeric Keypad (Numpad)) and your own custom templates (`~/.config/duckydeck-studio/profile_templates/`).
    • Copy Any Profile to a Template: Right-click any profile in the sidebar and choose 📋 Save Profile as Template... (or click 📋 Save as Template... in Profile Settings) to save its keys, scripts, colors, and orientations as a reusable template.
    • Apply a Template to an Existing Profile: Open 📋 Templates... and click Apply to Current Profile to overwrite the active profile with that template's layout.
  • ⚙ Profile Settings (OLED, Instant Desktop Widget Orientation & Profile Change Webhook): Click the ⚙ Profile Settings button in the center toolbar (or right-click a profile → Profile Properties...) to configure:
    • Hardware OLED Orientation (`0°`, `90°`, `180°`, `270°`): Rotates the physical duckyPad Pro OLED screen and key grid (`180°` & `270°` require DuckyDeck Studio Firmware `v1.0.0`).
    • 💻 Desktop Widget Orientation (`Follow OLED`, `0°`, `90°`, `180°`, `270°`): Independently orient the floating on-screen Desktop Widget (rotating both the key grid positions and the text labels inside each key) without changing how the physical duckyPad sits on your desk! Changes apply immediately and do not require a microSD card sync.
    • 🔔 Profile Change Webhook (On Profile Activated): Configure a per-profile HTTP webhook (`GET`/`POST`/`PUT`/`PATCH`/`DELETE`, URL, custom headers, and JSON body with placeholders `{{profile_number}}`, `{{profile_name}}`, `{{previous_profile_number}}`, `{{previous_profile_name}}`, `{{source}}`, `{{device_serial}}`, `{{timestamp}}`) that fires automatically whenever that profile becomes active.
    • Dim Unused Keys (`DIM_UNUSED_KEYS`): Automatically turns off LEDs on unconfigured keys.
  • Filter, Reorder & Fallback Protection:
    • Filter Profiles: Type in the profile filter box to filter by profile name or bound application; click the inline ✕ button inside the filter box to clear the filter.
    • Reorder Profiles: Hover over any profile to view the helper tooltip ("Drag ⠿ to Reorder • Double-click to Rename • Right-click for Options") and drag its ⠿ handle to reorder. All Auto-Switcher rules and the Fallback Profile setting automatically update to follow reordered profiles!
    • Protected Fallback Profile (`★ FALLBACK`): Every profile group automatically ensures a default Fallback Profile exists. The Fallback Profile cannot be deleted, and if another profile referenced by an Auto-Switcher rule is deleted, that rule automatically updates to reference the Fallback Profile.
  • Profile Groups (`.duckygroup.json`): Click Groups ▾ at the bottom of the sidebar (or in the `☰` menu) to save all profiles and Auto-Switcher rules into a single portable `.duckygroup.json` bundle, load an existing bundle, or start a fresh workspace (which automatically initializes Profile #1 as the Default Fallback Profile).

🎹 4. Interactive Hardware Canvas & OLED Simulator

  • Header-Footer Split Keycap Layout: Each keycap in the 4×5 matrix uses a clean, non-overlapping three-zone layout tested up to 115%+ UI zoom:
    • Top Header Bar: Compact key number (`1..20`) on the left next to the pill-shaped per-key RGB LED color bar on the right.
    • Center OLED Label Preview: Displays Line 1 and Line 2 labels (plus crisp 1-bit pixel-art icons) centered inside the keycap.
    • Bottom Footer Strip: Shows host-action pills (APP or API) on the left and repeat/abort indicators (↻ / ⏹) on the right.
  • Select / Deselect a Slot: Left-click any key (1–20), encoder action (21–26), or expansion slot (27–58) to open the Right Inspector. Click the selected key again (or click ✕ in the inspector header) to close the inspector.
  • Drag-and-Drop Swap vs. Shift:
    • Drag & Drop: Swaps the source key and target key (including scripts, labels, and custom RGB colors).
    • Shift + Drag & Drop: Inserts the dragged key at the target slot and shifts intermediate keys!
  • Right-Click Key Context Menu:
    • Copy Key X / Paste → Slot Y: Copy a key's full configuration and paste it onto another key (even across different profiles).
    • Set Key X Color: Opens the Color Picker window with your Saved & Used color palettes.
    • Clear / Reset Key X: Clears labels, scripts, and custom RGB color on that slot.
  • Toolbar Toggles:
    • ⚙ Profile Settings: Configure profile name, default LED color, Hardware OLED Orientation (`0°`, `90°`, `180°`, `270°`), instant Desktop Widget Orientation (`Follow OLED`, `0°`, `90°`, `180°`, `270°`), and Per-Profile Change Webhooks.
    • ⚡ 32ch: Show or hide the 4×8 (32-channel) Expansion Module panel (Slots 27–58).
    • OLED: Grid / Script: Preview either the standard 4×5 key label grid or custom `OLED_LINE` / `OLED_CIRCLE` / `OLED_RECT` drawing commands on the simulated 128×128 OLED screen.

🖼️ OLED Icon Library — Color UI & 1-Bit Monochrome Reference (204 Icons)

DuckyDeck Studio (v0.1.6) and Custom Firmware (DDS_FW v1.1.1) include 204 unique, zero-duplicate OLED icons (199 application & macro icons across 14 categories in the OLED Button Icon Picker, plus 5 keyboard modifier glyphs). Every icon is provided in both a Color Desktop UI version (rendered on the interactive Hardware Canvas and Floating Desktop OLED Widget) and a hand-crafted 1-Bit Monochrome Hardware OLED version (16×16 full-cell and 10×10 top-line pixel-art bitmaps compiled into oled_icons.c for the physical 128×128 SSD1306 OLED screen).

💡 Dual-Representation Storage (ui_zN/ui_xN + zN/xN)
When you assign an icon in the Key Inspector, DuckyDeck Studio writes the full UTF-8 symbol to ui_z<N>/ui_x<N> (decoded into 16×16 or 10×10 monochrome bitmaps by DDS_FW v1.1.1) and simultaneously writes the 4-character Stock ASCII Fallback to z<N>/x<N> so profiles remain 100% readable on stock DPP_FW firmware.

💾 6. microSD Sync, Mounting & Firmware Manager (`v1.0.0` & Official Catalog)

Edits you make in DuckyDeck Studio are saved immediately to your local profile cache (`~/.local/share/duckydeck-studio/profiles_cache/`) so you never lose work, even when the duckyPad is unplugged.

  • Mount SD Card (`☰ → Mount SD Card`): When an unmounted duckyPad microSD card (or USB Connected Duckypad) is detected, the `☰` menu displays Mount SD Card so you can mount it with one click without triggering a full sync.
  • Status Bar Sync Badge: The bottom status bar shows whether your local profiles match the hardware microSD card (✓ SD Synced vs. ⚠ Unsynced Changes). Host-only settings like Desktop Widget Orientation (`DW_ROTATION`) and Profile Change Webhooks apply immediately without requiring an SD sync.
  • 📋 Changes Summary: Click the sync status badge (or 📋 Summary) to inspect a per-profile diff of added, modified, or deleted keys before writing to hardware.
  • ⬆ Sync to SD: Mounts the duckyPad Pro microSD card (automatically via USB Mass Storage mode `0x1B` + `udisksctl`, or direct SD mount), compiles every `keyN.txt` script into a DSVM v2 `.dsb` binary, writes `config.txt` and `profile_info.txt`, flushes the filesystem, and verifies the written files.
  • DuckyDeck Studio Firmware (v1.1.1 — DDS_FW_1.1.1_eed0141e.bin) & Official Firmware Catalog Downloader:
    • Download Firmware Binary: ⬇ GitHub Release (DDS_FW_1.1.1_eed0141e.bin)  |  ⬇ Direct Download (DDS_FW_1.1.1_eed0141e.bin, IEEE CRC32: b3291568)
    • DuckyDeck Studio includes its own custom firmware build versioned as 1.1.1 (using the distinct DDS_FW_ prefix to separate it from official DPP_FW_ builds; based on upstream duckyPad-Pro 3.3.5 / DSVM v2, identified by the DuckyDeck Studio icon badge in the status bar and USB HID 0x00 signature bytes 'D','D','S').
    • Download Official Firmware List in Firmware Manager (☰ → Firmware Update...): Click ⬇ Fetch Official List from Site inside the Firmware Manager window to query the official dekuNukem/duckyPad-Pro repository, browse all available official firmware versions, and click ⬇ Download .bin or Download & Install Selected Firmware (with automatic IEEE CRC32 checksum verification).

🚀 8. Launch Application Builder (Linux & Windows)

💻 Host-Dependent Feature — Requires DuckyDeck Studio Running
Launching local desktop applications is not hardware-portable. DuckyDeck Studio must be running on your host PC (in the foreground or minimized to the system tray) to listen for the duckyPad's USB HID trigger and spawn the application.

Turn any duckyPad key into a one-press Linux or Windows desktop application launcher without writing shell scripts by hand.

  1. Select a key (1–20) to open the Right Inspector and click the 🚀 Launch App button in the editor toolbar.
  2. Check Launch Application on Key Press.
  3. Click 📦 Pick Installed App... to search all installed desktop applications on your OS—on Linux, it scans .desktop entries across /usr/share/applications, Flatpak exports, and ~/.local/share/applications; on Windows 10/11, it scans Start Menu .lnk shortcuts across %ProgramData%\Microsoft\Windows\Start Menu\Programs and %APPDATA%\Microsoft\Windows\Start Menu\Programs—or type any custom command, .exe path, and arguments.
  4. Choose from 165+ built-in OLED pixel-art icons across 13 categories (Browser, Word, Excel, Slides, Photo, CAD/3D, Media, Nav, Edit, System, Dev, Home, Badges) or use the hardware Record Key / Mouse Macro recorder (Linux evdev / Windows Win32 GetAsyncKeyState).
  5. Choose the Trigger Mode:
    • Silent Host Launch (`_GV31`) (Default — No Keyboard Shortcut Needed): Pressing the key on the duckyPad writes a unique profile+slot token to `_GV31`. DuckyDeck Studio's background HID listener detects the change and spawns the application directly on your Linux or Windows desktop!
    • F13–F24 Global Hotkey (`evdev` on Linux / Win32 `RegisterHotKey` on Windows): Emits `F13`–`F24` over USB HID keyboard and triggers the launch via DuckyDeck Studio's background global hotkey listener.
  6. Click ▶ Test Launch anytime to test the command immediately and inspect the result in the System Event Log (`APP_LAUNCH`).
🚀 Launch Application Builder — Configure desktop apps (Dolphin, Google Chrome, VS Code, OBS Studio, Konsole, Blender, Spotify, GIMP) with APP keycap badges and instant USB HID host launching.

🌐 9. Web API / Webhook Builder & 🏠 Home Assistant Entity Search

💻 Host-Dependent Feature — Requires DuckyDeck Studio Running
The duckyPad hardware does not have a network stack. Web API / Webhook keys and Home Assistant entity triggers require DuckyDeck Studio running on your host PC to receive the USB HID trigger and execute the HTTP request over your computer's network connection.

Trigger Home Assistant devices/entities, REST APIs, Miniflux, OBS, or custom HTTP endpoints directly from a duckyPad key:

  1. Select a key and click 🌐 Web API in the inspector toolbar (or open the full Web API / HTTP Webhook configurator window).
  2. 🏠 Search Home Assistant Devices & Entities:
    • Enter your Home Assistant URL (e.g. http://homeassistant.local:8123) and a Long-Lived Access Token (created in Home Assistant under Profile → Security → Long-Lived Access Tokens), then click Save HA Connection.
    • Select a domain filter (All Domains, light, switch, scene, script, automation, button, input_boolean, media_player, cover, fan, climate, lock), type a search query, and click 🔍 Search Entities.
    • Click ⚡ domain.service (or Turn On / Turn Off) next to any entity to automatically populate the HTTP POST endpoint (/api/services/<domain>/<service>), Authorization: Bearer header, JSON {"entity_id": "..."} body, and OLED feedback text for the selected key!
  3. Custom REST / Webhook Endpoints: Configure any HTTP Method (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`), URL, custom headers (`Header: Value` per line), and request body (JSON/text).
  4. Click Test Webhook Now to fire the HTTP request immediately and view status codes, latency, and errors in the System Event Log (`WEB_API`).

🪟 10. Window Auto-Switcher (KDE Plasma 6 Wayland & Windows 10/11 Win32) & Floating OLED Desktop Widget

💻 Host-Dependent Feature — Requires DuckyDeck Studio Running
Automatic window-based profile switching and the Floating OLED Desktop Widget require DuckyDeck Studio running on your Linux or Windows host PC. When DuckyDeck Studio is closed, you can still switch profiles manually using the physical + / - buttons on the duckyPad.

DuckyDeck Studio features a cross-platform active-window listener—using a native Rust + zbus KWin Wayland hook on Linux (KDE Plasma 6) and a native Win32 foreground window tracker (GetForegroundWindow + QueryFullProcessImageNameW) on Windows 10/11—to automatically switch duckyPad hardware profiles when you focus different windows or browser tabs.

  • 🎯 Crosshair Window Picker: Right-click any profile in the sidebar and select Bind Window to This Profile (Pick Window)... (or click Pick Window inside the Rules dialog). Click any open window on your Linux or Windows desktop to automatically capture its window class / executable name, window title, and application icon.
  • Filter & Reorder Rules: Filter rules using the search box (with an inline ✕ clear button) and hover over any rule row to view the helper tooltip ("Drag ⠿ to Reorder • Double-click to Edit • Right-click for Options").
  • Browser Tab Title & Regex Matching: When picking a web browser (Zen Browser, Firefox, Chrome, Edge, Brave, Vivaldi, etc.), DuckyDeck Studio automatically strips the browser suffix so your rule matches the specific web app or tab title (e.g. `Miniflux`, `GitHub`, `YouTube`), or you can use `*browser*` or regular expressions to match window titles.
  • Automatic Pause While Editing: Whenever the Right Key Inspector is open, the Auto-Switcher automatically pauses (`AUTO-SWITCHER (PAUSED)`) so switching to a browser or terminal to copy a URL or command won't yank the active profile away from the key you're editing!
  • Floating OLED Desktop Widget & 4-Way Rotated Key Labels: Mirrors the 128×128 OLED screen on your desktop with configurable scale (`1x`–`3x`), transparency (`0%`–`85%`, persisted across restarts), multi-monitor screen & position memory (KWin Wayland placement on Linux, Win32 HWND_TOPMOST on Windows), and instant independent per-profile orientation (`Follow OLED`, `0°`, `90°`, `180°`, `270°`) that rotates both the key grid positions and the text inside each key without requiring a microSD card sync.

  • PROFILE — Profile selection, creation, templates, renaming, reordering, and color changes
  • AUTOSWITCH — Active window focus changes (KWin Wayland or Windows Win32) and automatic profile switches
  • SD_SYNC — microSD mounting, `.dsb` bytecode compilation, and file validation
  • SCRIPT — Slot script saves and compiler diagnostics
  • WEB_API — HTTP webhook triggers, profile-change webhooks, status codes, latency, and response summaries
  • APP_LAUNCH — Application launch triggers, desktop IDs, PIDs, and error diagnostics
  • SYSTEM — Startup, REST API Server events, configuration persistence, and UI events

Logs are also persisted on disk at ~/.local/share/duckydeck-studio/logs/system_events.log on Linux or %LOCALAPPDATA%\duckydeck-studio\logs\system_events.log on Windows and can be filtered, copied, or exported to a `.log` file.

⚙️ 14. Settings, HTTP REST API Server & Security Implications

⚠️ Security Implications of the HTTP REST API Server — Please Read Before Enabling

1. Full Hardware & Host Control: Any client that can reach the HTTP REST API can switch, create, modify, or delete profiles and key scripts, synchronize bytecode to the microSD card, inject DuckyScript keystroke/mouse macros onto the host PC, control RGB LEDs and the OLED display, and execute host actions (APP_LAUNCH, WEB_API, SYS_ACTION) configured on slots.
2. Network Exposure (127.0.0.1 vs 0.0.0.0): The default listen IP 127.0.0.1 (port 28491) restricts access strictly to local processes on your computer. Changing the listen IP to 0.0.0.0 or a LAN IP exposes an unencrypted plain-HTTP server to all devices on your local network.
3. Token Authentication & Remote Access: Keep Require Bearer Token Authentication enabled at all times (clients must send Authorization: Bearer <token> or X-API-Token: <token>). Treat your generated 160-bit ddk_... token like a password, and never expose the plain-HTTP port directly to the public internet—use an HTTPS reverse proxy or SSH/WireGuard tunnel for remote access.

  • 🌐 HTTP REST API Server (`Settings → HTTP REST API Server`):
    • Enable or disable the embedded REST API server, choose the Listen IP (default 127.0.0.1) and Port (default 28491), or click Reset Defaults (127.0.0.1:28491).
    • Click Generate Token to generate a new cryptographic Bearer token and Copy Token to copy it to your clipboard.
    • Control all duckyPad functions via JSON endpoints under /api/v1/* (/api/v1/health, /api/v1/status, /api/v1/profiles, /api/v1/profiles/select, /api/v1/profiles/reorder, /api/v1/profiles/{num}, /api/v1/profiles/{num}/slots/{slot}, /api/v1/profiles/{num}/slots/{slot}/trigger, /api/v1/dsvm/compile, /api/v1/templates, /api/v1/pgv, /api/v1/leds, /api/v1/sd/sync, /api/v1/device/sleep|wake|reboot|sync-rtc, /api/v1/logs).
    • OpenAPI 3.0 / Swagger Specification & Reference: View docs/REST_API.md, docs/openapi.yaml, and docs/swagger.json, or fetch the live spec directly from the server at GET /api/v1/openapi.json, GET /api/v1/swagger.json, and GET /api/v1/openapi.yaml.
  • 🔔 Global Profile Change Webhook (`Settings → Global Profile Change Webhook`): Configure an HTTP webhook that fires automatically whenever the active profile changes (via UI, physical duckyPad buttons, Window Auto-Switcher, or REST API).
  • Global UI Text Zoom (`75%`–`160%`, Minimum `10pt` Base Font) & High-Contrast Controls: Adjust UI text zoom across the entire application using Ctrl++ / Ctrl+= (zoom in), Ctrl+- (zoom out), or Ctrl+0 (reset to `100%`), or via `Settings → Global Text Scale`. All checkboxes and scrollbars feature high-contrast borders in both Dark and Light modes, and all popup windows can be closed with Esc.
  • System Tray & Autostart (Linux & Windows): DuckyDeck Studio integrates natively with the KDE Plasma 6 System Tray (`StatusNotifierItem`) and the Windows 10/11 Notification Area, displaying a custom dynamic icon with your active profile number and color badge, live Profile & SD Sync status headers, Show / Hide DuckyDeck Studio, Toggle Desktop OLED Widget, Enable Window Auto-Switcher, Autostart at Login (XDG ~/.config/autostart/ on Linux; Registry HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DuckyDeckStudio on Windows), About DuckyDeck Studio, and Quit DuckyDeck Studio.

🛠️ 15. Troubleshooting & FAQ

❓ My Web API or Launch App key didn't trigger on the duckyPad

1. Ensure DuckyDeck Studio is running on your host PC (either open on screen or minimized to the system tray)—Launch App (`APP`) and Web API (`API`) actions are host-dependent and require DuckyDeck Studio's USB HID listener.
2. Check the bottom status bar—if it says ⚠ Unsynced Changes, click ⬆ Sync to SD so the compiled `.dsb` bytecode is written to the duckyPad's microSD card.
3. Open ☰ → System Event Log and filter by WEB_API or APP_LAUNCH to see the exact trigger event (`_GV31` or `F13–F24`) and any HTTP or process errors.

❓ Auto-Switcher isn't switching profiles right now

Check if the Right Key Inspector is currently open—Auto-Switcher intentionally pauses (`⏸ Paused (Editing Key N)`) while you are editing a key so your active profile doesn't jump away while you switch windows. Close the key editor (`✕`) to resume automatic switching.
