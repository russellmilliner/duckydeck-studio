DuckyDeck Studio — User Guide

☕ Support Russell Milliner on Ko-fi

DuckyDeck Studio is a native Linux configurator, DSVM v2 bytecode compiler, Wayland Auto-Switcher, and AI Macro Architect for the duckyPad Pro (2024) and duckyPad (2020), crafted with Rust, CXX-Qt, and KDE Plasma 6 Kirigami.

duckyPad Pro (0x0483:0xd11d) duckyPad 2020 (0x0483:0xd11c) DSVM v2 .dsb Bytecode Compiler KDE Plasma 6 Wayland Auto-Switcher Saved & Used RGB Palettes App Launcher & Web API Triggers

📦 1. Installation & USB HID Permissions

DuckyDeck Studio communicates directly with your duckyPad over USB HID (`hidraw`) for real-time profile switching, LED color previews, RTC clock sync, and Persistent Global Variables (`_GV0.._GV31`), and mounts or reads the duckyPad microSD card for profile storage.

⚡ One-Click Polkit udev Rule Setup
If Linux blocks non-root USB HID access (`PermissionDenied` on `/dev/hidraw*`), DuckyDeck Studio automatically displays an inline yellow banner at the top of the window. Click Install Rules to authorize the `70-duckypad.rules` installation via Polkit, or run: 
sudo ./data/udev/install-udev-rules.sh

🖥️ 2. The 3-Column Workspace

1️⃣ Left Column: Profiles & Auto-Switcher

Browse up to 64 hardware profiles, filter by profile name or bound application, drag-and-drop the ⠿ handle to reorder profiles, click any profile's color bar to change its default LED color (`BG_COLOR`), and monitor or configure KWin Wayland Auto-Switcher rules.

2️⃣ Center Column: Interactive Hardware Canvas

Interact with the 4×5 RGB key matrix (Keys 1–20), Dual Rotary Encoders (Slots 21–26), live 128×128 OLED screen simulator, and 32 Expansion Module channels (Slots 27–58). Drag and drop keys to swap or shift (`Shift + Drag`) slots.

3️⃣ Right Column: Key Inspector & Script IDE

Opens automatically when you click a key or encoder slot. Edit Line 1 / Line 2 OLED labels (up to 7 characters each), toggle Allow Abort and No Repeat, write `On Press` (`keyN.txt`) and `On Release` (`keyN-release.txt`) scripts, or configure no-code 🚀 Launch App and 🌐 Web API actions.

☕ Top Bar & Hamburger Menu (`☰`)

Displays the active application version, active profile badge, quick Default Color button, ☕ Buy Me a Coffee Ko-fi button, and the ☰ Hamburger Menu for SD sync, profile groups, PGV variables, System Event Log, Settings, and About.

🗂️ 3. Profiles & Profile Groups

The duckyPad Pro supports up to 64 profiles (`profile_1` through `profile_64`). Each profile stores its own default background LED color (`BG_COLOR`), per-key custom colors (`SWCOLOR`), key labels (`zN` / `xN`), and compiled bytecode binaries (`.dsb`).

  • Create a Profile: Click + New at the bottom of the left sidebar, type a name (up to 16 characters), and press Enter.
  • Reorder Profiles: Drag any profile by its ⠿ handle (or right-click and choose Move Profile Up / Down). Associated Auto-Switcher rules automatically update to follow the moved profile!
  • Right-Click Profile Context Menu: Right-click any profile in the sidebar to Select, Rename, Change Default LED Color (`BG_COLOR`), Bind Window to This Profile (Pick Window), Export Profile (`.duckyprofile.json` or Folder), or Delete.
  • Profile Groups (`.duckygroup.json`): Click Groups ▾ at the bottom of the sidebar (or in the `☰` menu) to save all profiles and Auto-Switcher rules into a single portable `.duckygroup.json` bundle, load an existing bundle, or start a fresh workspace.

🎹 4. Interactive Hardware Canvas & OLED Simulator

  • Select / Deselect a Slot: Left-click any key (1–20), encoder action (21–26), or expansion slot (27–58) to open the Right Inspector. Click the selected key again (or click ✕ in the inspector header) to close the inspector.
  • Drag-and-Drop Swap vs. Shift:
    • Drag & Drop: Swaps the source key and target key (including scripts, labels, and custom RGB colors).
    • Shift + Drag & Drop: Inserts the dragged key at the target slot and shifts intermediate keys!
  • Right-Click Key Context Menu:
    • Copy Key X / Paste → Slot Y: Copy a key's full configuration and paste it onto another key (even across different profiles).
    • Set Key X Color: Opens the Color Picker window with your Saved & Used color palettes.
    • Clear / Reset Key X: Clears labels, scripts, and custom RGB color on that slot.
  • Toolbar Toggles:
    • ↻ 90°: Toggle rotated layout orientation.
    • ⚡ 32ch: Show or hide the 4×8 (32-channel) Expansion Module panel (Slots 27–58).
    • OLED: Grid / Script: Preview either the standard 4×5 key label grid or custom `OLED_LINE` / `OLED_CIRCLE` / `OLED_RECT` drawing commands on the simulated 128×128 OLED screen.

🎨 5. Key & Profile Color Picker (Saved & Used Palettes)

Open the Color Picker by right-clicking any keycap and choosing Set Key X Color, clicking Key Color in the right inspector, or clicking Default Color in the top bar / center toolbar / profile sidebar.

🌈 Interactive HSV + RGB Controls

  • 2D Saturation / Value Square & Hue Bar: Drag the crosshair to blend shades visually.
  • R / G / B Sliders & SpinBoxes (`0–255`): Dial in exact hardware LED values.
  • Hex Input (`#RRGGBB`) & Old/New Swatch: Paste hex codes directly or click the Old swatch to revert.
  • System Picker...: Launch the native KDE/OS color dialog and screen eyedropper anytime.

📌 Saved Colors & Used Colors Palettes

  • Saved Colors Palette: Click + Save Current (`#RRGGBB`) to pin colors to your persistent palette (`~/.config/duckydeck-studio/kwin_rules.json`). Left-click to select, double-click to apply immediately, or right-click a swatch to remove it.
  • Used Colors Palette: Automatically lists every unique color currently used in any profile's `BG_COLOR` or key's `SWCOLOR` across all loaded profiles. Left-click to reuse a color, or right-click a Used Color swatch to add it to your Saved Colors!
  • Reset to Profile Default: When editing a key color, click Reset to Profile Default to remove its custom `SWCOLOR` and inherit the profile's `BG_COLOR`.

💾 6. microSD Sync & Validation

Edits you make in DuckyDeck Studio are saved immediately to your local profile cache (`~/.local/share/duckydeck-studio/profiles_cache/`) so you never lose work, even when the duckyPad is unplugged.

  • Status Bar Sync Badge: The bottom status bar shows whether your local profiles match the hardware microSD card (✓ SD Synced vs. ⚠ Unsynced Changes).
  • 📋 Changes Summary: Click the sync status badge (or 📋 Summary) to inspect a per-profile diff of added, modified, or deleted keys before writing to hardware.
  • ⬆ Sync to SD: Mounts the duckyPad Pro microSD card (automatically via USB Mass Storage mode `0x1B` + `udisksctl`, or direct SD mount), compiles every `keyN.txt` script into a DSVM v2 `.dsb` binary, writes `config.txt` and `profile_info.txt`, flushes the filesystem, and verifies the written files.

📜 7. duckyScript 3 & Built-In DSVM v2 Bytecode Compiler

DuckyDeck Studio includes a full, pure-Rust duckyScript 3 → DSVM v2 (`.dsb`) bytecode compiler with real-time syntax checking and KDE `KSyntaxHighlighting`.

  • Live Bytecode Verification: As you type in the script editor, the header badge shows ✓ Valid DSVM (N B) or highlights the exact line number and syntax error.
  • On Press vs. On Release Tabs: Every key and slot supports both an On Press (`keyN.txt`) script and an On Release (`keyN-release.txt`) script.
  • 📖 Command Reference Drawer: Click 📖 Reference in the script toolbar to browse and insert all duckyScript 3 commands (`STRING`, `STRINGLN`, `DELAY`, `KEYDOWN`, `KEYUP`, `SWCC`, `SWCF`, `SWCR`, `OLED_PRINT`, `OLED_LINE`, `OLED_RECT`, `OLED_CIRCLE`, `OLED_UPDATE`, `IF/ELSE/END_IF`, `WHILE/END_WHILE`, `FUNCTION/END_FUNCTION`, `GOTO_PROFILE`, `_GV0.._GV31`, etc.).

🚀 8. Launch Application Builder

Turn any duckyPad key into a one-press Linux application launcher without writing shell scripts by hand.

  1. Select a key (1–20) to open the Right Inspector and click the 🚀 Launch App button in the editor toolbar.
  2. Check Enable App Launch on this key.
  3. Click 🔍 Choose Installed App... to search all installed desktop applications (`.desktop` entries from `/usr/share/applications`, Flatpak exports, and `~/.local/share/applications`) with icons, descriptions, and categories—or type any custom command and arguments.
  4. Choose the Trigger Mode:
    • Instant USB HID via `_GV19` (Default — No Keyboard Shortcut Needed): Pressing the key on the duckyPad writes a unique slot token to `_GV19`. DuckyDeck Studio's background HID listener detects the change within ~180ms and spawns the application directly on your Linux desktop!
    • F13–F24 Global Hotkey (`evdev`): Emits `F13`–`F24` over USB HID keyboard and triggers the launch via DuckyDeck Studio's background `evdev` listener.
  5. Click ▶ Test Launch anytime to test the command immediately and inspect the result in the System Event Log (`APP_LAUNCH`).

🌐 9. Web API / Webhook Builder

Trigger Home Assistant webhooks, REST APIs, Miniflux, OBS, or custom HTTP endpoints directly from a duckyPad key:

  1. Select a key and click 🌐 Web API in the inspector toolbar.
  2. Check Enable Web API Call on this key and configure the HTTP Method (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`), URL, custom headers (`Header: Value` per line), and request body (JSON/text).
  3. Select HID PGV (`_GV18`) (zero keyboard interference, works on all profiles and keys) or F13–F24 Hotkey.
  4. Click ▶ Test Call to fire the HTTP request immediately and view status codes, latency, and errors in the System Event Log (`WEB_API`).

🪟 10. KDE Plasma 6 Wayland Auto-Switcher

DuckyDeck Studio features a native Rust + `zbus` listener that integrates with KDE Plasma 6's KWin Wayland compositor to automatically switch duckyPad hardware profiles when you focus different windows or browser tabs.

  • 🎯 Crosshair Window Picker: Right-click any profile in the sidebar and select Bind Window to This Profile (Pick Window)... (or click Pick Window inside the Rules dialog). Click any open window on your desktop to automatically capture its `resourceClass`, window title, and application icon.
  • Browser Tab Title Matching: When picking a web browser (Zen Browser, Firefox, Chrome, Brave, Vivaldi, etc.), DuckyDeck Studio automatically strips the browser suffix so your rule matches the specific web app or tab title (e.g. `Miniflux`, `GitHub`, `YouTube`), or you can use `*browser*` to match all web browsers.
  • Automatic Pause While Editing: Whenever the Right Key Inspector is open, the Auto-Switcher automatically pauses (`AUTO-SWITCHER (PAUSED)`) so switching to a browser or terminal to copy a URL or command won't yank the active profile away from the key you're editing!

🔢 11. Persistent Global Variables (`_GV0`..`_GV31`)

Open Variables (`_GV`)... from the `☰` menu to inspect and live-edit all 32 32-bit non-volatile Persistent Global Variables (`_GV0` through `_GV31`) over USB HID commands `0x18` (read) and `0x19` (write) in Signed Decimal, Unsigned Decimal, or Hexadecimal format.

Reserved Bridge PGVs (`_GV18` & `_GV19`)
DuckyDeck Studio uses _GV18 for instant Web API triggers and _GV19 for instant Application Launch triggers when using the default USB HID PGV trigger mode.

✨ 12. AI Macro Architect

Click ✨ AI in the Right Inspector header (or AI Macro Architect... in the `☰` menu) to generate duckyScript 3 macros using natural language. DuckyDeck Studio grounds prompts with your local KDE shortcuts (`~/.config/kglobalshortcutsrc`) and validates the generated script with the built-in DSVM v2 compiler.

📋 13. System Event Log

Open System Event Log... from the `☰` menu (or from the About window) to view real-time diagnostic events across all subsystems:

  • DEVICE — USB HID connection, firmware checks, RTC sync, and reboots
  • PROFILE — Profile selection, creation, renaming, reordering, and color changes
  • AUTOSWITCH — KWin Wayland window focus changes and automatic profile switches
  • SD_SYNC — microSD mounting, `.dsb` bytecode compilation, and file validation
  • SCRIPT — Slot script saves and compiler diagnostics
  • WEB_API — HTTP webhook triggers, status codes, latency, and response summaries
  • APP_LAUNCH — Application launch triggers, desktop IDs, PIDs, and error diagnostics
  • SYSTEM — Startup, configuration persistence, and UI events

Logs are also persisted on disk at ~/.local/share/duckydeck-studio/logs/system_events.log and can be filtered, copied, or exported to a `.log` file.

⚙️ 14. UI Text Scaling & System Tray Integration

  • Independent Per-Area Text Scaling (`75%`–`160%`): Open Settings... from the `☰` menu to adjust text scaling across the entire app at once or independently for:
    • Left Sidebar (Profiles & Auto-Switcher)
    • Center Hardware Canvas (Keycaps, Encoders, OLED & Toolbar)
    • Right Key Inspector & Action Builders
    • duckyScript 3 Code Editor & Command Reference
    • Bottom Status Bar
    • System Event Log Window
  • System Tray (`StatusNotifierItem`): DuckyDeck Studio integrates natively with the KDE Plasma 6 System Tray, displaying a custom dynamic icon with your active profile number and color badge, quick profile switching submenu, and optional Minimize / Close to System Tray behavior.

🛠️ 15. Troubleshooting & FAQ

❓ My Web API or Launch App key didn't trigger on the duckyPad

1. Check the bottom status bar—if it says ⚠ Unsynced Changes, click ⬆ Sync to SD so the compiled `.dsb` bytecode is written to the duckyPad's microSD card.
2. Open ☰ → System Event Log and filter by WEB_API or APP_LAUNCH to see the exact trigger event (`_GV18` / `_GV19` or `F13–F24`) and any HTTP or process errors.

❓ Auto-Switcher isn't switching profiles right now

Check if the Right Key Inspector is currently open—Auto-Switcher intentionally pauses (`⏸ Paused (Editing Key N)`) while you are editing a key so your active profile doesn't jump away while you switch windows. Close the key editor (`✕`) to resume automatic switching.
